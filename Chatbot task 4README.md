## Task 2 - Stock Portfolio Tracker

A Python program that calculates total investment based on predefined stock prices and user-entered quantities.

### Features

- Uses a Python dictionary to store stock prices
- Accepts stock names and quantities
- Calculates individual investment
- Calculates total investment
- Saves the result to a text file

### Technologies

- Python
- Dictionary
- User Input/Output
- Arithmetic Operations
- File Handling

### Sample Output

AAPL: 5 shares × $180 = $900

Total Investment: $900
